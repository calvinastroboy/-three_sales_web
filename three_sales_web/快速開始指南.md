# THREE 商品系列分析系統 - 快速開始指南

歡迎使用 THREE 商品系列分析系統！這份指南將幫助您在 5 分鐘內啟動並使用這個工具。

## 🎯 這個工具能做什麼？

只需上傳 4 個文件：
1. 官網銷售數據（Excel）
2. MOMO 銷售數據（Excel）
3. 美麗台採購單（PDF）
4. 分類定義（Excel）

系統會自動：
- 整合三個通路的銷售數據
- 智能匹配產品到對應分類
- 統計各分類在各通路的業績
- 生成標準格式的 Excel 報表

## 🚀 三步開始使用

### 步驟 1：啟動應用

**如果您有 Docker**（推薦）：
```bash
cd three_sales_web
docker-compose up --build
```

**如果沒有 Docker**：
```bash
cd three_sales_web
pip install -r requirements.txt
flask run
```

### 步驟 2：打開網頁

在瀏覽器中訪問：`http://localhost:5000`

### 步驟 3：上傳文件並分析

1. 點擊四個上傳區域，分別選擇對應的文件
2. 點擊「執行分析」按鈕
3. 等待 10-30 秒
4. 點擊「下載 Excel 報表」

完成！您已經獲得了標準格式的商品系列分析報表。

## 💡 常見問題

### Q: MOMO 文件是 .xls 格式，能用嗎？

**A**: 建議先轉換為 .xlsx 格式：
1. 在 Excel 中打開 S1201Report.xls
2. 文件 → 另存為 → 選擇「Excel 工作簿 (.xlsx)」
3. 保存後上傳

### Q: 有些產品顯示「未分類」？

**A**: 這些產品在分類定義文件中找不到匹配項。您可以：
1. 更新 `分類定義.xlsx`，添加這些產品的標準名稱
2. 重新上傳並分析

### Q: 我想讓團隊其他人也能使用？

**A**: 您有三個選擇：
1. **最簡單**：在您的電腦上啟動應用，告訴同事訪問 `http://您的IP:5000`
2. **推薦**：部署到 Render.com（免費），獲得一個公開網址
3. **企業級**：部署到公司內網伺服器

詳細部署步驟請參考 `README.md` 文件。

### Q: PDF 中的數據沒有正確提取？

**A**: 目前 PDF 解析是硬編碼的（基於您提供的樣本）。如果 PDF 格式變化：
1. 聯繫技術人員更新 `analyzer.py` 中的 `load_pdf_data` 方法
2. 或者將 PDF 內容手動複製到 Excel 後上傳

### Q: 報表格式不對？

**A**: 報表格式是根據您提供的「輸出格式樣板.xlsx」生成的。如果需要調整：
1. 修改 `analyzer.py` 中的 `generate_report` 方法
2. 或者下載報表後在 Excel 中手動調整

## 📞 需要幫助？

如果遇到技術問題，請檢查：
1. Python 版本是否為 3.8 或更高
2. 所有依賴是否正確安裝（`pip list` 查看）
3. 文件格式是否正確（Excel 應為 .xlsx，PDF 應為可選取文字的格式）
4. 瀏覽器控制台是否有錯誤訊息（按 F12 打開）
